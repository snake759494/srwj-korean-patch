# v2.5 — 원문에 없는 것이 번역에 들어가 있던 세 부류

이슈 [#2](https://github.com/snake759494/srwj-korean-patch/issues/2)·[#3](https://github.com/snake759494/srwj-korean-patch/issues/3)·[#4](https://github.com/snake759494/srwj-korean-patch/issues/4) 는 증상이 전혀 달라 보였지만, 파고들어 보니 모두 **원문에는 없는 정보를 번역이 임의로 채워 넣어** 생긴 문제였습니다.

## 1. 고른 기체·이름이 번역에 못박혀 있었습니다 (#4)

주인공 기체는 플레이어가 고릅니다(그란티드 / 쿠스트웰 / 벨제루트). 원문은 그래서 **이름을 쓰지 않고 지시어로만** 가리킵니다 — `あれ`, `これ`, `こいつ`, `あの機体`. 그런데 번역이 특정 이름을 박아 넣어, 쿠스트웰을 고른 플레이어에게 "그랑티드"가 보였습니다.

| 원문 | 이전 | v2.5 |
|---|---|---|
| `あれは絶対に破壊されてはいけない` | 하지만 **그랑티드를** 뺏기거나 | 하지만 **그 기체를** 뺏기거나 |
| `あの機体を守らなきゃならない` | 당부한 대로 **그랑티드를** | 당부한 대로 **그 기체를** |
| `こいつだって性能はいいんだ` | **그랑티드도** 성능은 좋아 | **이 녀석도** 성능은 좋아 |
| `今はこれが私たちのすべてだから` | 지금은 **벨제루트가** 저희의 전부 | 지금은 **이 기체가** 저희의 전부 |
| `あれがアシュアリー・クロイツェルと` | 그 **벨제루트라는** 로봇이 | 그 로봇이 |
| `力を手にした君が` | 너에겐 그 **그랑티드라는** 힘이 | 너에겐 그 힘이 |
| `そう、あなたならできるわ` | 네가 **그랑티드의** 적임자라는 | 네가 적임자라는 |
| `③の最初の時を思い出すなぁ` | ③가 처음 **그랑티드에** 탔을 때 | ③가 처음 탔을 때 |

주인공 이름도 같은 문제가 2건 있었습니다. `これで最初の予定通り` 에 "칼비나 씨를 파일럿으로 영입하려던"이, `ですからあなたも安心して` 에 "토우야도"가 들어가 있어 반대 주인공을 고르면 어긋났습니다.

전투 대사 11,271항목도 같은 기준으로 검사했고 이쪽은 0건이었습니다.

## 2. 34화에서 소스케가 남의 말을 옮기는 것처럼 보였습니다 (#2)

같은 장면에 **두 판본**이 있습니다.

| 화자ID | 상황 | 원문 |
|---|---|---|
| `0xCC` | 본타군(쿠르츠가 통역) | `『大佐殿、機体から飛び降りて下さい！』って！` |
| `0xC9` | 소스케가 직접 말함 | `大佐殿、機体から飛び降りて下さい！` |

그런데 **직접 발화 쪽에까지 통역 말투를 붙여** 놓았습니다. 본타군을 얻지 않은 루트에서는 소스케 얼굴로 "'대령님, 기체에서 뛰어내리세요'라고 하네!" 가 떠서, 제보하신 대로 화자가 어긋난 것처럼 보였습니다.

```
이전   ’대령님, 기체에서 뛰어내리세요’라고 하네!
v2.5   대령님, 기체에서 뛰어내리세요!
```

34화 해당 구간 **11건**을 원문대로 직접 발화로 되돌렸습니다. 본타군 판본(0xCC)은 원문에 `『』…って` 가 있으므로 통역 말투 그대로 두었습니다.

## 3. 서브파일럿 판본의 경어가 뒤바뀌어 있었습니다 (#3)

같은 장면에 서브파일럿별 판본이 2~3개씩 있고, 원문은 `①さん` / `①` 로 공손함을 구분합니다. 번역이 이걸 **반대로** 붙여 놓은 곳이 있었습니다.

| 원문 | 이전 번역 | v2.5 |
|---|---|---|
| `①、あれ！` (평어) | ① **씨**, 저길 **보세요!** | ①, 저길 봐요! |
| `①さん、あれ！` (경칭) | ①, 저길 봐요! | ① **씨**, 저길 **보세요!** |

44화 2건, 그리고 같은 식으로 뒤바뀐 97·111블록 2쌍까지 모두 **4쌍 8건**을 원문에 맞췄습니다.

## 고치지 못한 것

[#3](https://github.com/snake759494/srwj-korean-patch/issues/3) 의 1·2번(테카맨 레이피어 합류 조건, 아렌비 미합류 중 중간 대사)은 **누가 합류하는지 결정하는 게임 쪽 조건**이라 한글 패치가 손댈 수 없는 부분입니다. 이 패치는 글자와 그림만 바꿉니다. 관련 조건 문구(`レイピア撃墜` → `레이피어 격추`)도 원문대로 번역돼 있어 오해를 부를 번역은 없었습니다.

## 검증

전투 대사 폭 초과 0건 / 4줄 이상 0건 / 일본어 잔존 0건 / 인코딩 실패 0건, 시나리오 짤림은 기존 2건(arc191, 비대사 데이터)뿐입니다. 0~4단계를 다시 빌드해 xdelta 역적용으로 결과 ROM이 일치하는 것을 확인했습니다.
