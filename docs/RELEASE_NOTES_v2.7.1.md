# v2.7.1 — 닫았던 이슈 둘을 다시 열어 고쳤습니다

[v2.7](RELEASE_NOTES_v2.7.md) 에서 **해결하지 못한 채 남겨 둔 두 건**을 다시 파고들어 고쳤습니다. 둘 다 처음 판단이 틀렸습니다.

---

## 1. 23화 증원 대사 — 게임 버그가 아니라 번역이 맞바뀌어 있었습니다 (#30)

제보 내용은 이랬습니다.

> 23화 아크엔젤 루트에서 **캐서린이 격추되지 않았는데도** 쟝갈이 증원 올 때 **'캐서린 격추 후' 대사**가 나옵니다.

v2.7에서는 "어떤 조건에 어떤 대사를 띄울지는 게임 쪽 이벤트가 정한다"고 보고 닫았습니다. **그 판단이 틀렸습니다.** 같은 장면의 **조건별 두 판본**을 원문과 하나씩 맞춰 보니 **번역이 서로 맞바뀌어** 있었습니다.

| 턴 | 조건 | 일본어 원문 | v2.7까지의 번역 |
|---|---|---|---|
| `t280` | 캐서린이 **그 자리에 있을 때** | `わかっておる。ここまで戦力を低下させた奴らを…` | 길이 엇갈리는 바람에 못 봤지만 **캐서린은 후퇴했나 보군** … |
| `t281` | 캐서린이 **이미 빠졌을 때** | `行き違いでカザリーンは撤退したか。だがここまで…` | **알고 있네** … |

`わかっておる`(알고 있네)는 바로 앞에서 캐서린이 「하지만 적의 전력을 감소시킨 건 사실입니다」라고 말한 데 대한 **대답**입니다. 즉 캐서린이 **있을 때** 쓰이는 판본인데, 번역이 반대쪽 판본의 내용을 받아 「캐서린은 후퇴했나 보군」이 떴습니다.

```
v2.7.1  t280  알고 있네 / 전력을 이 정도로 감소시켜놓은 상황에서 …
        t281  길이 엇갈리는 바람에 못 봤지만 / 캐서린은 후퇴했나 보군 …
```

같은 유형(판본 쌍의 번역이 맞바뀜)을 **전 35,268턴에 대해 전수 감사**했고, 뒤바뀐 쌍은 **이 하나뿐**이었습니다.

## 2. 32화 카티아 대사 (#45)

v2.7에서 「카티아:....그렇습니다」 한 줄을 번역 데이터에서 찾지 못해 남겨 두었던 건입니다. 보내 주신 스크린샷을 다시 보고 찾았습니다 — 32화 **맵 출격 직전** 대사였습니다.

```
토우야  카티아, 갈 수 있겠지              (カティア、行けるな)
카티아  ... 그렇습니다                    (・・・はい)        ← 혼자만 존댓말
토우야  카티아...
카티아  ... 아무것도 아니야 / 가자, ○○    ← 바로 다음 줄은 반말
```

같은 장면의 **테니아 판본은 반말, 멜루아 판본은 존댓말**로 원문 그대로인데, **카티아 판본만** 어긋나 있었습니다.

```
v2.7.1   ... 응
```
