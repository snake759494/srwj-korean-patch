## v2.3 (2026-08-24) — 전투 대사 화자명 미출력 수정 + 2~6화 제보

### 이름이 사라지던 이유 (#25 · #29 · #31)

시나리오 대사는 줄바꿈할 때 첫 줄에 화자명 자리 7칸을 미리 비워 둡니다. 그런데 **전투 대사 줄바꿈에는 그 예약이 없었습니다.** 화면에서 첫 줄 앞에 `이름「` 이 붙는 순간 대사창을 넘고, 넘긴 줄은 통째로 빈 줄이 됩니다. 이름까지 같이 사라지므로 "이름이 안 나온다"로 보였습니다.

#31 의 레이즈너 회피 스크린샷으로 실측했습니다.

```
번역    피하긴 했지만 움직임이 / 좋다…, 다음에도 / 잘된다는 보장은 없군
화면    (빈 줄)              / 좋다…, 다음에도 / 잘된다는 보장은 없군

첫 줄 12칸 + '에이지「' 4칸 = 16칸  →  대사창 초과 → 첫 줄이 통째로 사라짐
```

첫 줄 예산을 14칸 → **10칸**으로 낮춰 이름 4자(+`「`)까지 들어가게 했습니다.

- 대상 **172건** 중 **162건**은 글자를 하나도 바꾸지 않고 줄바꿈 위치만 다시 잡았습니다
- 3줄에 들어가지 않는 **10건**은 문장을 줄였습니다
- 합체기 블록(193)은 바이트 길이 보존 대상이라 손대지 않았습니다

### 대사창 빈칸 과다 (#8)

`뻗어라      빔 리본` 처럼 대사 중간이 휑하게 벌어지는 증상이 있었습니다. 삽입기가 일반 공백을 전각 공백으로 바꾸는데, 번역문이 원문의 `！　`(느낌표+전각공백)를 그대로 둔 채 뒤에 공백을 한 번 더 넣고 있었습니다. **310건**을 한 칸으로 정리했습니다. 폭이 줄기만 하므로 짤림 위험은 없습니다.

### 무장명 단위 표기 통일 (#20 · #25)

v1.9에서 6개만 `ｍｍ`/`Ｍ` 로 바꿔 두어 나머지는 `밀리`·`미리`·`센티`가 섞여 있었습니다. 원문에 `ミリ`/`センチ`/`メートル` 가 있고 숫자 뒤인 것만 **45건** 통일했습니다. 전각 2바이트끼리 교체라 슬롯 길이는 그대로입니다.

| | |

| `９３．７센티화선포` | `９３．７ｃｍ화선포` |
