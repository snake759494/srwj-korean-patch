# v2.7 — 제보 38건, 그리고 그 뒤에 있던 네 가지 원인

이슈 [#13](https://github.com/snake759494/srwj-korean-patch/issues/13)~[#50](https://github.com/snake759494/srwj-korean-patch/issues/50) **38건**을 반영했습니다. 10일 동안 1화부터 34화까지 플레이하며 하나하나 적어 주신 **Peoggy** 님께 감사드립니다.

개별 오타도 많았지만, 파고들어 보니 **원인이 하나인 묶음이 넷** 있었습니다.

## 1. 여는 따옴표가 닫는 따옴표로 찍혔습니다 (#19 #42 #47 #50)

본타군의 통역문이 `'알겠습니다, 소령님!'` 처럼 **양쪽 다 닫는 따옴표**로 나왔습니다. `"토이박스"`, `"우리의 적"`, `'헐!?'` 도 같은 증상이었습니다.

원인은 번역이 아니라 **코덱**이었습니다. 삽입 엔진이 ASCII 따옴표를 전각으로 바꿀 때 이렇게 하고 있었습니다.

```python
'"': '”',   "'": '’',     # ← 여는 자리인지 닫는 자리인지 보지 않는다
```

여는 자리·닫는 자리를 번갈아 맞추도록 고쳤습니다([`srwj_codec.py`](../0.%EC%8B%9C%EB%82%98%EB%A6%AC%EC%98%A4/srwj_codec.py)의 `pair_quotes`). 번역 데이터 쪽도 전수 정리했습니다 — **157개 턴**.

```
이전   마오「’알겠습니다、소령님!’ 이란다!」
v2.7   마오「‘알겠습니다、소령님!’ 이란다!」
```

## 2. 전투 대사가 통째로 안 나왔습니다 (#18)

카티아가 「타겟 포착! ○○, 지금이야!」 하고 외친 뒤 토우야 얼굴만 뜨고 **대사창이 빈 채로** 넘어갔습니다.

전투 대사에는 실행 중에 글자로 바뀌는 **인라인 코드**가 들어 있습니다.

| 코드 | 바뀌는 내용 | 길이 |
|---|---|---|
| `[7d]` | 이름 (카티아·토우야…) | 3칸 |
| `[7e]` | 기체명 | 최대 8칸 |
| `[7f]` | 무기명 | 최대 10칸 |

그런데 [v2.4](RELEASE_NOTES_v2.4.md)에서 넣은 균형 줄바꿈이 이것들을 **'화면에 안 그려지는 제어문자'(폭 0)** 로 보고 앞 줄에 붙여 버렸습니다. 실행할 때 무기명이 들어가면 줄이 창을 넘고, 넘긴 줄은 잘리는 대신 **통째로 안 그려집니다.**

```
원문    わかってる！ / [7f]！        ← 무기명을 따로 둔다
v2.3.1  알고 있어! / [7f]!
v2.4    알고 있어! [7f]!            ← 한 줄로 붙음 → 실행 시 사라짐
v2.7    알고 있어! / [7f]!
```

원문이 코드를 따로 둔 항목 **62건**을 원문 구조대로 되돌리고, 줄바꿈 도구와 감사 도구가 이 코드들의 실제 폭을 세도록 고쳤습니다([`rewrap_balance.py`](../2.%20전투대사패치/rewrap_balance.py), [`audit_battle_width.py`](../2.%20전투대사패치/audit_battle_width.py)). 이제 같은 실수가 감사에서 걸립니다.

## 3. 기체 이름 뒤 조사가 빠져 있었습니다 (#27 #31 #45 #48)

주인공 기체 이름은 플레이어가 고른 기체로 바뀌는 변수(`⑤`)입니다. 그 뒤에 **조사가 통째로 빠진** 턴이 많았습니다.

| 원문 | 이전 | v2.7 |
|---|---|---|
| `⑤を狙う` | ⑤ 노릴 거야! | ⑤**를** 노릴 거야! |
| `⑤がなければ` | 확실히 ⑤ 없으면 | 확실히 ⑤**가** 없으면 |
| `⑤は正常` | ⑤ 정상. | ⑤**는** 정상. |
| `⑤に乗る` | ⑤ 타기로 했잖아 | ⑤**에** 타기로 했잖아 |

원문 조사를 하나씩 확인해 **46개 턴**을 채웠습니다. 주인공 이름 변수(`②③`) 뒤가 빈 턴도 함께 고쳤습니다.

## 4. 화자 이름이 사라졌습니다 (#15)

11화 아크엔젤 루트에서 발트펠트의 이름이 **나왔다 안 나왔다** 했습니다.

이 게임은 일부 대사에서 **본문 안에 화자 이름을 품고** 있습니다(`バルトフェルド「…」`). 번역에서 그 이름이 빠진 턴이 있었고, 그 턴만 이름 없이 그려졌습니다.

```
원문    バルトフェルド「もし君が“ユニウス７”への核攻撃を…」
이전    만약 자네가 ‘유니우스 7’에 대한 핵공격을…
v2.7    발트펠트「만약 자네가 ‘유니우스 7’에 대한 핵공격을…」
```

발트펠트 **9턴**과 베살리우스 함장 1턴, 모두 **10턴**을 채웠습니다.
